# 📦 EntityManager

> **EntityManager управляет сущностями в игровом мире, обеспечивая их состояние и историю.**

## 🎯 Назначение

- Хранение и управление состоянием сущностей
- Поддержка истории изменений сущностей
- Обеспечение согласованности данных между сервисами
- Поддержка snapshot/replay для восстановления состояния

## 🔄 Жизненный цикл

1. Получает события `entity.created`, `entity.updated`, `entity.deleted` через `entity_events`
2. Обновляет состояние сущности в MinIO
3. Сохраняет историю изменений
4. Публикует подтверждения операций

## 🧠 Состояние EntityManager

- Хранит состояние сущностей в MinIO
- Поддерживает историю изменений
- Использует snapshot/replay для восстановления состояния
- Обеспечивает изоляцию данных по миру (buckets: `entities-{world_id}`)

## 📡 Обработка событий

1. Подписывается на `entity_events` с типами `entity.created`, `entity.updated`, `entity.deleted`
2. Извлекает данные сущности
3. Обновляет состояние в MinIO
4. Сохраняет историю изменений
5. Публикует подтверждения

## 🌐 Интеграция

- **WorldGenerator**: создание сущностей мира
- **GameService**: взаимодействие с игроками
- **NarrativeOrchestrator**: контекст для повествования
- **SemanticMemory**: семантический контекст

## ✅ Преимущества

- Состоятельные сущности с историей
- Поддержка восстановления состояния
- Изоляция данных по миру
- Гибкость в управлении сущностями

## 🛠️ Техническая реализация

- Сервис реализован в пакете `services/entitymanager`
- Использует `eventbus.EventBus` для подписки на события
- Подписывается на `eventbus.TopicEntityEvents`
- Использует MinIO для хранения данных

## 🔧 Конфигурация

- Переменные окружения: `MINIO_ENDPOINT`, `KAFKA_BROKERS`
- По умолчанию: `localhost:9000`, `localhost:9092`

## 📊 Мониторинг

- Количество созданных/обновленных сущностей
- Размер хранилища сущностей
- Время операций с сущностями
- Количество snapshot'ов
