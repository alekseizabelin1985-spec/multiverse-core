# 📚 OntologicalArchivist

> **OntologicalArchivist отвечает за хранение и управление онтологическими схемами и сущностями.**

## 🎯 Назначение

- Хранение версионированных схем сущностей
- Поддержка онтологической целостности
- Обеспечение доступа к схемам для других сервисов
- Управление версиями схем

## 🔄 Жизненный цикл

1. Получает запросы на сохранение/получение схем через `system_events`
2. Хранит схемы в MinIO с версионированием
3. Обеспечивает доступ к схемам по запросу

## 🧠 Состояние OntologicalArchivist

- Хранит схемы в MinIO с версионированием
- Использует путь `schemas/{type}/{name}/v{version}.json`
- Поддерживает историю версий схем
- Не хранит состояние между запросами

## 📡 Обработка событий

1. Подписывается на `system_events` с типом `schema.save` и `schema.get`
2. Извлекает данные схемы
3. Сохраняет или возвращает схему из MinIO
4. Обеспечивает версионирование

## 🌐 Интеграция

- **WorldGenerator**: получение схем для генерации мира
- **UniverseGenesisOracle**: сохранение сгенерированных схем
- **EntityManager**: использование схем для сущностей
- **SemanticMemory**: контекст для индексации

## ✅ Преимущества

- Версионирование схем
- Онтологическая целостность
- Централизованное хранение схем
- Поддержка обратной совместимости

## 🛠️ Техническая реализация

- Сервис реализован в пакете `services/ontologicalarchivist`
- Использует `eventbus.EventBus` для подписки на события
- Подписывается на `eventbus.TopicSystemEvents`
- Использует MinIO для хранения схем

## 🔧 Конфигурация

- Переменные окружения: `MINIO_ENDPOINT`, `KAFKA_BROKERS`
- По умолчанию: `localhost:9000`, `localhost:9092`

## 📊 Мониторинг

- Количество сохраненных схем
- Размер хранилища схем
- Количество запросов к схемам
- Количество версий схем
