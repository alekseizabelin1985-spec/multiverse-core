# 🧘 AscensionOracle

> **AscensionOracle — это специализированный AI-сервис, обеспечивающий философскую целостность и генеративность в ответах.**

## 🎯 Назначение

- Генерация высококачественных AI-ответов с философской глубиной
- Поддержка "генеративности вместо скриптов" (generativity vs scripts)
- Обеспечение семантической целостности в контенте
- Предоставление контекста для других AI-сервисов

## 🔄 Жизненный цикл

Сервис работает как **stateless сервис**:

1. Получает запросы через `system_events`
2. Обрабатывает контекст и генерирует ответ
3. Возвращает результат

## 🧠 Состояние AscensionOracle

- Не хранит состояние между запросами
- Использует Qwen3 для генерации
- Обеспечивает философскую целостность и семантическую глубину

## 📡 Обработка событий

1. Подписывается на `system_events` с типом `oracle.request`
2. Извлекает контекст и параметры запроса
3. Генерирует ответ с философской глубиной
4. Публикует результат в `system_events`

## 🌐 Интеграция

- **UniverseGenesisOracle**: контекст для генерации вселенных
- **NarrativeOrchestrator**: контекст для повествования
- **SemanticMemory**: семантический контекст
- **WorldGenerator**: контекст для генерации мира

## ✅ Преимущества

- Философская целостность в генерации
- Генеративность вместо скриптов
- Семантическая глубина в AI-ответах
- Интеграция с другими AI-сервисами

## 🛠️ Техническая реализация

- Сервис реализован в пакете `services/ascensionoracle`
- Использует `eventbus.EventBus` для подписки на события
- Подписывается на `eventbus.TopicSystemEvents`
- Использует Qwen3 для генерации

## 🔧 Конфигурация

- Переменные окружения: `ORACLE_URL`, `KAFKA_BROKERS`
- По умолчанию: `http://localhost:8080`, `localhost:9092`

## 📊 Мониторинг

- Количество обработанных запросов
- Время генерации
- Качество сгенерированных ответов
- Использование ресурсов AI-модели
