# 📋 PlanManager

> **PlanManager управляет стратегическими и тактическими планами для игроков и NPC.**

## 🎯 Назначение

- Создание и управление стратегическими планами
- Агрегация и выполнение тактических задач
- Поддержка многопользовательского планирования
- Генерация планов на основе контекста игрового мира

## 🔄 Жизненный цикл

Управляется **через системные события**:

| Событие | Действие |
|--------|---------|
| `plan.created` | Создание нового плана |
| `plan.updated` | Обновление плана |
| `plan.deleted` | Удаление плана |
| `plan.executed` | Выполнение части плана |
| `plan.completed` | Завершение плана |
| `plan.failed` | Неудачное выполнение плана |

## 🧠 Состояние PlanManager

- Хранит данные о всех планах в памяти
- Отслеживает статус выполнения задач
- Поддерживает историю изменений планов
- Может быть расширен до сохранения в базе данных

## 📡 Обработка событий

1. Получает события от `player_events` и `world_events`
2. Извлекает информацию о целях и контексте
3. Генерирует или обновляет планы
4. Публикует события о состоянии планов

## 🌐 Интеграция

- **EntityManager**: получение данных о сущностях
- **WorldGenerator**: контекст мира
- **GameService**: взаимодействие с игроками
- **SemanticMemory**: поиск контекста для планирования

## ✅ Преимущества

- Стратегическое мышление в игре
- Поддержка комплексных задач
- Масштабируемость через события
- Гибкость в управлении планами

## 🛠️ Техническая реализация

- Сервис реализован в пакете `services/planmanager`
- Использует `eventbus.EventBus` для подписки на события
- Обрабатывает события из `eventbus.TopicPlayerEvents`, `eventbus.TopicWorldEvents`
- Подписывается на группы `plan-manager-group`, `plan-world-group`

## 🔧 Конфигурация

- Переменные окружения: `KAFKA_BROKERS` (по умолчанию `localhost:9092`)
- Подписывается на группы событий для управления планами

## 📊 Мониторинг

- Статистика созданных планов
- Количество активных планов
- Статус выполнения задач
- Время на создание и выполнение планов
