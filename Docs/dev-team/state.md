## Действия пользователя (открыты)
- Отозвать токены и ключ, найденные в истории (GITHUB_TOKEN, DB_MCP_TOKEN, ORACLE_API_KEY).
- Создать форк minio/minio в своём аккаунте (нужен для сборки образа хранилища).
- Установить PowerShell 7 (или использовать вариант скриптов для Git Bash).
- Прислать вывод `llama-server --version` для пина сборки; провести замер моделей на стенде.
- После первого зелёного прогона CI: branch protection и required checks в настройках репозитория.
