# Заинтересованные стороны

Версия 1.1 · 2026-09-09 · product-owner. Обновлено по решениям discovery
(раунды 1–5, `journal.md`): рой GM на Agent GM Core, фоновая жизнь в MVP,
Telegram первым, целевое железо. Проект ведёт один человек в нескольких ролях;
стороны, которых пока нет физически, перечислены, чтобы видеть, чьи интересы
мы представляем без их участия, и когда они появятся.
