### T-474: `state` — предложения без ответа после восстановления State · Размер: M · Статус: todo · Исполнитель: developer TEAM-1 (назначает оркестратор) · Подволна 1.7 · Ветка: `task/T-474-unanswered-proposals` · ревью — code-reviewer TEAM-1; правка КД — через system-architect

По КД `state-and-mechanics.md` §4.8 восстановление при догоне `ReadRange(system_events, cursor, End)` пропускает `*.proposed` («уже породили факты или были отклонены»), а приём предложений начинается с `Tail(system_events, End)`. Ответ предложения всегда стоит в журнале после него, а старый процесс к моменту `End` уже не публикует, поэтому признак «ответа нет» по диапазону полон.
