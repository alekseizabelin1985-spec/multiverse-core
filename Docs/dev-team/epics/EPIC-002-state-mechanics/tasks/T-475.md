## Описание и DoD
См. раздел «### T-475» в `../tasks.md`. Кратко: `world init --bus kafka` предлагает сущности фикстур State процесса `core` через Redpanda. Что уже создано, решают объекты `entities-{world}`, а не журнал: retention `system_events` — 30 дней. Снапшот seq 0 `bootstrap` команда просит у admin-маршрута T-059, `--force` на этом пути — `exit 2`. Заодно закрывается хвост ревью #2 T-058:
- N-3 — тест ветки «`snapshot.created` не вышел»;
- N-4 — `errors.Join` для ошибки `Stop`;
- `--force` над повреждённым указателем;
- подсказка `world status` для `minio`;
- `details` отказа в тексте для оператора.

**Оценка размера — M.** Новый путь CLI: шина Kafka, HTTP-клиент admin-маршрута, чтение объектов. Опция `Bootstrap` для правила объектов. Тесты на внедрённой шине и на State теста с маршрутом на `httptest`. Пять небольших правок пути memory с тестами и мутантами. Риск роста — способ запросить `reason=bootstrap` у маршрута (решение system-architect до кода). Запасной план — части А и Б в индексе.
