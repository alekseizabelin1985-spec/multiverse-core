## Описание и DoD
Главный источник — раздел «### T-303» в [`../tasks.md`](../tasks.md): описание, DoD задачи и DoD-common (§0). Карточка DoD не дублирует; если они расходятся, прав индекс. Кратко:
- `links`: `Resolve`, `Consent`, `AttachPlayer`, `Forget` с `ForgetHooks`, `RouteFor`, `character_requests`; `Link.LogValue` без внешнего ID.
- HTTP: router, middleware 1–8, `handlers_links.go`; `errors.go` из T-301 расширяется. Своего `http.Server` нет: маршруты монтируются на mux сервера процесса `runtime.NewHTTP` (`MV_CORE_ADDR`).
- Настоящий контекст `gateway` регистрируется в `cmd/multiverse/contexts.go` вместо заглушки, имя регистрируется один раз.
- SEC-11/12: `client_unknown`, `actor_kind_forbidden`, `client_mismatch`, `413`, `poll_in_progress`; списки клиентов читаются через `env.GatewayClientIDs` и `env.GatewayActorKindClients`.
