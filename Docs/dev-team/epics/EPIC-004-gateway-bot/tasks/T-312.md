## Описание и DoD
Главный источник — раздел «### T-312» в [`../tasks.md`](../tasks.md): описание, DoD задачи и DoD-common (§0). Карточка DoD не дублирует; если они расходятся, прав индекс. Кратко:
- Цикл доставки: `429` → `retry_after`, `5xx` → 3 попытки без ack, `403`/`400` → ack.
