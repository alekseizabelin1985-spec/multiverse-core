**Отклонения от дизайна и решения по ходу.**
1. **`check` инварианта равен его id** (`check: inv-01`), а не имени вида `dead_does_not_act` из примера КД §12.1. КД §10.4 и ADR-012 п. 5 требуют, чтобы `check` совпадал с `mechanics.Invariant.ID`, а id в `invariants.go` — `inv-01…inv-10`. Пример §12.1 написан до перехода на двузначные id. У `inv-11` ключ свой — `laws_version_current`.
2. **Набор известных `check` повторён в `internal/laws`** (`KnownChecks`): пакет не видит `mechanics` (depguard). `Config.Checks` позволяет рою передать ключи, которые механика реально реализует. Сверку двух списков делает T-238.
3. **`Bump` требует, чтобы файл `--from` был документом каталога законов** (совпадение содержимого). КД не говорит, где лежит файл. Без этого `mvctl` мог бы объявить версию, которой нет у `core`.
4. **Базовая версия без состояния** — старшая `approved`, кроме объявляемой: файл `vN+1` уже лежит в каталоге и сам по себе стал бы «текущим».
5. **Более новая версия, которая не загружается, — ошибка `Current`, а не пропуск**: возможно, именно её автор считал текущей.
6. **`source=mvctl` у обоих событий `Bump`** — константа. В MVP-1 `Bump` зовёт только `mvctl laws bump`, публикует процесс `mvctl` (C-02 v1.5). У `core/laws` (E-B) нет права издателя `entity.update.proposed`; когда пробой будет объявлять версии, издателя придётся передавать параметром и добавить в реестр.
7. **`proposal_id = laws:{world}:{version}`** — по образцу `bootstrap:{world}:{type}/{id}` (C-02 v1.5): повтор `bump` той же версии State гасит по id.
8. **`Watch` не блокирует подписку**: канал на 16 уведомлений, при переполнении — `Warn` и пропуск. Потеря уведомления ничего не ломает: агенты берут `Current` при сборке каждого промпта (КД §12.2).
9. **`Health` возвращает `runtime.Status`**, а не собственный тип: так его проще встроить в `/health` роя (T-239).
10. **`mvctl laws show` без `--world`** берёт `MV_WORLD_ID`; `--world=` показывает все миры каталога. strain в отдельном процессе CLI всегда нулевой — вывод это оговаривает.
11. **`main_test.go` (файл EPIC-001) изменён двумя строками:** `laws` убрана из списка зарезервированных имён и добавлена в список реализованных. Иначе `TestReservedNamesAreHeld` падает на реализованной команде. Нужен просмотр tech-lead#1.
12. **`mvctl laws check`** (обещание комментария `internal/mechanics/invariants.go` и бэклога T-054) в T-205 не входит: DoD прямо отдаёт сверку id T-238, а `testdata/laws-v1.invariants.yaml` T-054 в этой ветке нет — он в EPIC-002. Предложение — в бэклоге ниже.
