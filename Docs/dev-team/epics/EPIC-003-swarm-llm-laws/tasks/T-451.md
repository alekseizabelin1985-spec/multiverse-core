### Решения по ходу
1. **Сигнатура `IsLocalEndpoint(rawURL) (bool, error)` не менялась.** Раньше функция шла через `EndpointHost`, где нет проверки порта, any-address и формы. Теперь идёт через `parseEndpoint` с именем переменной `URL`, как `llm_endpoint_classify` по умолчанию. Класс для теста: ошибка `ErrConfig` → invalid, `true` → local, `false` → cloud. Отдельный экспортный тип класса не вводил: контракт его не требует.
2. **Классы адресов — методы `netip`** (`IsUnspecified`, `IsLoopback`, `IsPrivate`, `IsLinkLocalUnicast`) после `Unmap`. Их диапазоны совпадают с правилом: `127/8` и `::1`; RFC 1918 и `fc00::/7`; `169.254/16` и `fe80::/10`. Список `rfc1918` удалён. IPv4-compatible `::127.0.0.1` и NAT64 не распаковываются: `Unmap` снимает только `::ffff:`.
3. **Прайс-таблица использует ту же функцию `isLocalHost`.** Однословное имя, `*.localhost`, link-local и ULA теперь стоят 0 в `Cost`, а цена ≠ 0 для них отвергается при загрузке. `EndpointHost("http://ollama.:11434")` = `ollama.`: у такого хоста цены нет, `Cost` вернёт `ErrNoPrice` (закрыто по умолчанию, а не бесплатно). Шапка `config/llm-prices.yaml` приведена к правилу.
4. **Голый IPv6-литерал.** Go 1.26.8 по умолчанию отвергает `http://::1:8888`, но при `GODEBUG=urlstrictcolons=0` разбирает его как хост `::1` и порт 8888. Отдельная проверка держит класс независимым от переключателя рантайма. Тест переключает `GODEBUG` через `t.Setenv` и пропускается, если переключатель перестанет действовать.
5. **Toolchain.** Под `go1.25.3` (системный Go вне модуля) `url.Parse` отвергает все IPv4-mapped литералы в скобках (`invalid IPv6 host`), под `go1.26.8` принимает. Модуль закрепляет `toolchain go1.26.8`, расхождения с таблицей нет. Это обнаружено пробой по всем строкам таблицы в scratch.
6. **Порядок проверок** — как в скриптах, где это видно по классу: any-address раньше «нет порта» (`http://0.0.0.0` отвергается как any-address), userinfo раньше query.
