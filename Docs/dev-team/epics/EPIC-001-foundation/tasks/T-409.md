## Выполнение (architect#1)

Модель ниже плановой: по профилю архитектор идёт на Fable, лимит Fable в сессии исчерпан — работа выполнена на Opus.

Все 73 строки разделов «Расхождения с деревом» 17 диаграмм (24 различных расхождения) сверены. У каждой строки — статус в таблице под заголовком раздела своей диаграммы: закрыто, снято, код (с задачей) или открыто (с причиной). Код не менялся.

Внесено по решениям оркестратора:
1. C-05 v1.3 п. 1 — повтор при конфликте версий под тем же `proposal_id`, только для `version_conflict`, с уточнениями 1а–1в из ревью #2 T-219 и T-400 (конфликт принадлежит пакету; повтор гаснет с первым фактом, отказ дедуплицируется; повтор, меняющий живых, пересчитывает конец боя или не предлагается).
2. C-05 v1.3 п. 3 — встреча не отвечает на непринятое действие; потребитель различает состояние по `encounter.started`/`encounter.ended`.
3. C-01 v1.3 — `Deps` по коду: без `Store` и `Env`, с `Mux`.
4. C-02 v1.4 — `set status` в то же значение у нетерминальной сущности — факт без изменений; правка кода — EPIC-002 T-056.
5. Подкоманда отчёта — `mvctl report` во всех документах области.

Плюс T-404/T-408 в документах: `MV_LLM_URL` — единственный источник, обязательный, без значения по умолчанию, `/v1` допустим, `MV_LLM_PORT` выведен; `MV_MODE`/`MV_BUS` — манифест, флаги перекрывают, `kafka|memory`; адрес процесса — только `MV_CORE_ADDR`; профили `bot`/`legacy` — отдельные файлы compose.

Решение по `shared/agent/levels.go` — **ADR-025**: единственная истина таблицы владения — существующий `shared/contracts/ownership.go`, копии и теста равенства нет; `levels.go` — производный вид. Требует подтверждения system-architect.
