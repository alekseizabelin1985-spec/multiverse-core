### Решения по ходу
- **Порядок `All()` сохранён.** Аналитика шлюза (`analytics.session.*`, `analytics.turn.completed`) стояла в блоке «в» после типов роя. Строгая склейка «по владельцу» подняла бы три типа вверх и изменила порядок объявления, который `All()` обещает. Поэтому у шлюза два списка в одном файле: `gatewayDefinitions` (блок «а») и `gatewayAnalyticsDefinitions`. Аналитика читается рядом с аналитикой EPIC-005, а побайтное сравнение дампа реестра проходит.
- **Легаси-типы остаются в `registry.go`**: их владелец — EPIC-001, отдельный `registry_foundation.go` добавил бы файл без выгоды.
- **`foundation()` — в `main.go`**: файл и так EPIC-001, там же `runVersion`. У EPIC-004 подкоманд нет, файла `commands_gateway.go` нет.
- **Имена файлов владельцев EPIC-003/005** в `cmd/mvctl` — `commands_swarm.go` и `commands_ops.go`, по именам функций из решения (`swarmCmds`, `opsCmds`). Они совпадают с `ownership.md` v0.6: `commands_state.go` — строка EPIC-002, `commands_swarm.go` — строка EPIC-003, `commands_ops.go` — строка EPIC-005. *(Итерация 2, ревью #1 N-4: прежняя фраза «названо только `commands_state.go`» была неверна.)*
- **`factoryOf` через `switch`, а не карту.** Имя и переменная сопоставлены в одном месте; забытая переменная — паника в `init` с именем контекста, а не `nil`-фабрика, которая упадёт только при `--contexts`.
- **`SetDeadlines` при длительности ≤ 0 не трогает дедлайн** этого направления. Так маршрут ограничивает одно направление, не сбрасывая другое. Решение этого не оговаривало; записано в doc-комментарии.
- **`ShuttingDown` вне сервера процесса возвращает `nil`-канал.** `select` на нём не срабатывает, поэтому обработчик под `httptest` ведёт себя как без остановки.
- **`registerPackageSetup` при ошибке регистрации не паникует в `init`**: ошибка копится, `TestMain` печатает её одной строкой и выходит с кодом 1 до подготовок. Сообщение читается лучше трассы паники. Тест `TestRegisterPackageSetupReachesTestMain` проверяет, что функция пишет в реестр `TestMain`; он же держит её в сборке, пока ни один эпик её не зовёт (иначе `unused`).
