## Описание
Бот Telegram (`cmd/telegram-bot/**`, EPIC-004) — тонкий клиент gateway (ADR-018; КД gateway-and-bot §3; дополнение ADR-001, граница 1e). Из `internal/*` ему доступны только клиент C-10 и типы протокола: `internal/gateway/client` и `internal/gateway/api`, по одному пакету, с якорем `$`. Шину, в том числе `membus`, бот не импортирует.

Сейчас в `.golangci.yml` правила для бота нет. Шаблон `**/internal/**` правила `internal-unlisted` совпадает с `cmd/telegram-bot/internal/**` и запрещает даже два разрешённых пакета. Задача вносит правило и исключение по тексту, проверенному tech-lead#1 при отметке владельца T-310. Внесение правила — условие старта T-311.

В ветке EPIC-001 кода бота нет, поэтому на ней правило ничего не меняет. Проверка на коде бота — в копии кончика `epic/EPIC-004-gateway-bot`.

## DoD

В `.golangci.yml` внесено правило `cmd-telegram-bot` ровно по тексту карточки T-310: комментарий, `files`, разрешённые `internal/gateway/client$` и `internal/gateway/api$`, запреты `multiverse-core.io/internal` и `multiverse-core.io/shared/eventbus` с `desc`. Правило стоит перед `cmd-others`. В `internal-unlisted` добавлено исключение `!**/cmd/telegram-bot/**` с комментарием.
