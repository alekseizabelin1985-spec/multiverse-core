### Отклонения от решения
1. **Шаблон файлов тестов.**
   - В решении — `**/internal/swarm/**/*_test.go`. depguard сопоставляет `files` как glob с разделителем `/`, и `**/…/*` требует хотя бы одного вложенного каталога. Поэтому тесты в самом `internal/swarm` под шаблон не попадают: мутант D1 красный от `internal-swarm`, D2 зелёный.
   - Записан `**/internal/swarm/**_test.go`: те же файлы на любой глубине, включая корень (P2, P2n, L1, L2). Смысл правила тот же, изменилось только написание glob.
   - Так же записаны шаблоны `internal-memory` и `internal-memory-tests`.
2. **`internal-memory-tests`.** Решение говорит «`fake$` — только для тестов», но правило не называет. Сделано по образцу роя: пара из production-правила и тест-правила.
3. **Листовые правила разрешают сам пакет** (`internal/swarm/template$`, `internal/gateway/client$`). Иначе внешний тест `template_test` не мог бы импортировать свой пакет (P8).
4. **«Одно из двух» у `unknown_entity` — это `oneOf`**, то есть ровно одно. `entity` и `background_ref` вместе отвергаются (держит S15).
5. **Невалидная фикстура `llm.output.rejected`** теперь ломает условие: `budget_exceeded` вместе с `llm_output`.
   - Прежний дефект `reason: "budget"` по новой схеме нарушал бы сразу два правила — enum и ветку `else`. README требует ровно одного.
   - Ловушку словаря держит новый случай «budget used as a reason» в `TestBlockVPayloadRejects`. В нём `llm_output` есть, так что ломается только enum.

   - Мутант L16: тест роя импортирует `internal/gateway/gatewaytest`, находку `internal-swarm-tests` скрывает исключение, результат зелёный. Под HEAD (H-L16) было красным.

   - (в) оставить исключение и добавить `internal/gateway/gatewaytest$` в `allow` нужных тест-правил.

   Реализован (а), буквально по решению. Нужно решение system-architect.
