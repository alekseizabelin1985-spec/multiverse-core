## Описание и DoD
- **Причина (T-410)**: `multiverse serve …` падает с `unexpected argument "serve"`, флаги передаются сразу; CLAUDE.md (карта каталогов и «Прямые команды Go»), задания команды и, возможно, runbook пишут `serve`. Было и до T-410.
- **DoD**: выбрать одно из двух с обоснованием — (а) `serve` принимается явной подкомандой (и синонимом запуска без подкоманды, чтобы композиция и Makefile не сломались), или (б) документы исправлены на запуск без подкоманды. В обоих случаях: тест на форму, которая остаётся; грэп по дереву и `Docs/ops` — нигде не осталось неработающей формы.
- **Исполнитель**: developer. Файлы `cmd/multiverse/` — после приёмки T-410 (тот же `serve.go`).

## Выполнение (developer)
Исполнитель — developer#1 (TEAM-1). Окончание 2026-09-11 16:45 (+03:00); начало — по журналу оркестратора. Не закоммичено: файлы в индексе.

**Выбор — (а): `serve` стал явной подкомандой, запуск без подкоманды остался её синонимом.**

Почему (а), а не (б):
- Без подкоманды платформу запускают четыре места: `ENTRYPOINT ["/multiverse"]` в образе вместе с `command: ["--contexts=…"]` у трёх сервисов compose, `make replay` и e2e-тест. Эту форму нельзя убрать ни при (а), ни при (б), поэтому она остаётся.
- С подкомандой пишут CLAUDE.md, README и AGENTS.md («serve/health/db»), задания команды и оператор. Рядом уже есть `health`, `db` и `version`.
- (б) закрепило бы асимметрию: три подкоманды и одна команда без имени. Опечатка вида `multiverse helth` по-прежнему уходила бы в разбор флагов `serve` и отвечала бы `unexpected argument`, ничего не сказав о том, какие подкоманды бинарник знает.
- (а) — правка одного `main.go`, и ни один запуск не ломается.

**Что сделано.**
- `main.go`: `run` → `dispatch(args, stdout, stderr, start)`. Если первого аргумента нет или он начинается с `-` (флаги с одним и с двумя дефисами), это `serve`. `serve` снимает своё имя и передаёт остальное в тот же `runServe`. Затем `health`, `db`, `version`. Любое другое слово — код 2 и отказ `unknown subcommand "<слово>": expected serve, health, db or version, or the flags of serve without a subcommand`. Список подкоманд задан одним срезом `subcommands`, отказ печатает его через `joinOr`.
- `serve.go`: `runServe` принимает `start startFunc`, в бинарнике это `serve`. Так тест проходит настоящий диспетчер и настоящий разбор флагов и не упирается в процесс, который остановит только сигнал. Больше в `serve.go` ничего не менялось.
- Документы: CLAUDE.md — карта каталогов (`serve`, «то же без подкоманды», `version`) и «Прямые команды Go» (`go run ./cmd/multiverse serve …` с пометкой, что `serve` можно опустить); README — карта каталогов.
