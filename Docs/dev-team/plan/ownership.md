# Карта владения

Версия 0.4 · 2026-09-09 · system-architect#1 (утверждено на G2 в v0.2; ведёт tech-lead#1). **Изменения v0.4 (сведение 3, `consolidation.md` §14):** копия таблицы владения `shared/contracts/ownership.go` и процедура правки «истина `levels.go` → копия тем же PR» (`contracts.md` §16 п. 6); `Spec.Publishers` в реестре — владелец типа перечисляет издателей (§16 п. 7); имена env `MV_TELEGRAM_ALLOWED_USER_IDS` (единое), `MV_KAFKA_BROKERS` для CLI на хосте, `MV_SWARM_REPLAY_WAIT`, `MV_TELEGRAM_CLOUD_FLAG_TTL`.
